## 🔭 Currently

My strategic core is a three-pillar **agent-tooling stack** — *write patterns → gate outputs → observe runs*:

- 📚 **[Agentic Recipes](https://github.com/sauravbhattacharya001/agentic-recipes)** — canonical agentic pipeline patterns on promptlib (.NET): 14 recipes spanning research/summarize chains, tool-agent ReAct loops, RAG, plan-and-execute, self-consistency voting, multi-agent debate, reflexion & tree-of-thoughts (*write the patterns*)
- 🧪 **[agent-eval](https://github.com/sauravbhattacharya001/agent-eval)** — zero-dependency TypeScript toolkit for evaluating AI agent outputs three ways: an eval framework, fleet monitoring, and a CI quality gate (*gate the outputs*)

- 🛡️ Building **[WinSentinel](https://github.com/sauravbhattacharya001/WinSentinel)** — always-on Windows security agent · **v1.19.1** live · 34 audit modules, AI-powered correlation & auto-remediation
- 📱 Building **[FeedReader](https://github.com/sauravbhattacharya001/FeedReader)** — native iOS RSS reader with offline caching & image support · **v1.15.0** — quiet hours, outage forecasting & goal tracking
- 🤖 Running **[AgentBox](https://sauravbhattacharya001.github.io/getagentbox/)** — AI agents as a service, open access
- 🔤 Evolving **[sauravcode](https://github.com/sauravbhattacharya001/sauravcode)** — my own programming language with f-strings, try/catch, and zero noise · **v7.10.0** — code immune system & security hardening

## 🔬 Research

- **AI Agent Identity & Accountability** — frameworks for governing autonomous agents in distributed systems
- **AI Self-Replication Safety** — contract-enforced sandboxes to study and contain agent replication behaviors
- **AI Agent Evaluation** — independence-first testing for hallucination detection, drift monitoring, staleness/no-op detection, and behavioral assertions, with CI gating for agent runs
- **Agent Observability & Explainability** — tracing and explaining *why* an autonomous agent reached a decision, not just *what* it did
- **Agentic Pipeline Patterns** — composable orchestration architectures for reliable multi-step AI workflows
